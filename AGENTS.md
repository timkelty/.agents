## Question-first gate

If a user message contains a question—or a `?` outside inline or fenced code:

1. Stop all tool use, commands, edits, planning, and previously requested work.
2. Answer every question directly.
3. End the turn after answering.
4. Do not begin or resume action until the user sends a later message explicitly telling you to proceed.

When a message mixes questions with action requests, this rule takes precedence.
